omokage面影

パーツを組み合わせて作る SVG アバターと、選んでカスタマイズできるピッカー。人物・妖怪・どうぶつ・ゲームキャラの 4 つの絵柄。<script> 1 本で使えます。

組み込みデモ GitHub

絵柄

使い方

HTML だけで

名前（seed）から毎回同じアバターが決まります。

<span data-omokage="animals" data-seed="tanaka"
      style="width:48px"></span>
<script src="https://cdn.jsdelivr.net/gh/kobesoft-labs/omokage@0/dist/omokage.min.js"></script>

ピッカーで選んでもらう

保存するのは { style, config } の小さな JSON だけ。

const avatar = await Omokage.openPicker({ value: saved });
if (avatar) save({ style: avatar.style, config: avatar.config });
el.innerHTML = Omokage.render(saved);
